# Duplicate File Finder & Universal File Searcher

A Windows desktop application for searching files and detecting duplicate files across drives and folders.

## Features

### File Search

- Search files by filename
- Partial filename search
- Search across all drives
- Search a specific drive
- Search a selected folder
- Open file location
- Copy file path

### Duplicate Finder

- Scan all drives
- Scan a specific drive
- Scan a selected folder
- Detect duplicates using SHA-256 hashing
- File size pre-filtering for better performance
- View duplicate groups
- Calculate potential reclaimable disk space
- Open duplicate file locations
- Stop running scans safely

## Technology

- Python
- PySide6
- SHA-256 hashing
- QThread
